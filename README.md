# icu-availability-and-scheduling-system-8659-8671

Frontend app path: `frontend_react_app`

Quick start:
- cd icu-availability-and-scheduling-system-8659-8671/frontend_react_app
- npm install
- npm start

SCSS compilation:
- The React app uses SCSS in several components. Ensure the Sass compiler is available.
- If you see "Can't resolve 'sass'" during start/build, run:
  - npm install --save-dev sass
  - or yarn add -D sass
  - or pnpm add -D sass
